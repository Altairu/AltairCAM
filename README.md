# AltairCAM

**PCB CNC加工用CAMソフトウェア**

KiCad等で設計したPCBをCNCマシンで自作加工するための、軽量かつ高機能なツールパス生成ソフトウェアです。
ガーバーファイルとExcellonドリルファイルを読み込み、最適な切削用Gコードを出力します。

## 📥 ダウンロード ＆ インストール

AltairCAMは、Windows用のインストーラー（推奨）またはPythonソースコードから直接実行できます。

### 方法1. Windows版インストーラーで導入する（推奨）
Python環境の構築なしに、すぐに独立したアプリケーションとしてお使いいただけます。専用のオリジナルアイコンも付属しています。

1. GitHubの [Releasesページ](https://github.com/Altairu/AltairCAM/releases) (※配布準備中の場合、リポジトリの `dist` フォルダ) から **`AltairCAM-1.x-win64.msi`** をダウンロードします。
2. ダウンロードした `.msi` ファイルをダブルクリックしてインストーラーを起動します。
3. 画面の指示に従いインストールを完了させます。
4. スタートメニューから `AltairCAM` を起動して利用開始！

### 方法2. ソースコードから実行・開発する
開発者向け、またはMac/Linux環境向けのセットアップ方法です。

```bash
# 1. リポジトリをクローン
git clone https://github.com/Altairu/AltairCAM.git
cd AltairCAM

# 2. 依存パッケージをインストール
pip install -r requirements.txt

# 3. アプリケーションを起動
python src/main.py
```

※ **開発者向けTips:** `python build_msi.py bdist_msi` を実行することで、ご自身で最新のWindows用MSIインストーラーを構築可能です。(`cx_Freeze` が必要です)

## ✨ 主な機能

### コア処理
- ✅ **高度なガーバーファイル解析** - RS-274X形式に完全対応
- ✅ **Excellonドリルファイル解析** - decimal/integer形式の両対応
- ✅ **レイヤー個別管理** - B_Cu（銅箔）、Edge_Cuts（基板外形）、Drill（穴）を個別に設定可能
- ✅ **ベタ塗り・配線のシームレス結合** - `shapely` ライブラリの統合により、物理的につながったネッツを1つの外枠として自動で削り出します

### ツールパス最適化
- ✅ **精密なアイソレーション** - カッパーの厚みや各種形状を正確にマージ＆オフセット
- ✅ **円弧補間処理** - 高精度な円弧の直線近似（0.05mm単位）と太さ(Width)のサポート
- ✅ **移動経路の最短化** - Nearest Neighbor法によりドリル等の移動距離を最大60%削減
- ✅ **パス簡潔化** - Ramer-Douglas-PeuckerアルゴリズムでGコード量を軽量化

### 充実したUI機能
- ✅ **2D・3Dプレビュー** - 切削結果を立体表示・回転・ズームで確認可能
- ✅ **切削シミュレーション** - Gコードの動きを画面内でアニメーション再生
- ✅ **反転(Mirror)機能** - 統一基準点に基づく裏面加工対応
- ✅ **個別Gコード出力** - 用途に応じてレイヤーごとにファイルを分割可能

## 📖 使い方

### 1. KiCadからファイルをエクスポート

**ガーバーファイル:**
1. PCBエディタ → ファイル → プロット
2. フォーマット: Gerber
3. 含めるレイヤー: `B.Cu`（裏面銅）、`Edge.Cuts`（外形）
4. プロットをクリック

**ドリルファイル:**
1. 同じダイアログで「ドリルファイルの生成」をクリック
2. フォーマット: Excellon, 単位: ミリメートル
3. ドリルファイルを生成をクリック

### 2. ファイル読み込みとパラメータ設定

1. AltairCAMを起動し、各ファイルセクションでエクスポートしたファイルを選択します。
2. その後「すべて読み込み」をクリックしてプレビューに表示させます。
3. 各レイヤーごとにツール直径や送り速度、深さを指定します。
   - **B_Cu（銅箔）**: ツールの太さに合わせて0.1〜0.2mm程度、深さは -0.05mm など
   - **Edge_Cuts（外形）**: 基板の厚みに合わせて -1.8mm など
   - **Drill（穴）**: 最適化（ツールパス最適化）チェックを「ON」にするのがおすすめです。

### 3. Gコード生成
各セクションの「Gコード生成」ボタンを押し、CNCソフトに読み込ませるファイルを出力します。
> **💡 加工テンプレ順**: (1) B_Cu（アイソレーション） → (2) Drill（穴） → (3) Edge_Cuts（切り出し）

## 🔧 トラブルシューティング

**Q: Gコードが生成できない / エラーが出る**
A: ログウィンドウにエラー内容が表示されます。配線やベタの結合に失敗する場合は、ガーバー出力時のフォーマットが正しいか確認してください。

**Q: ドリル穴がうまく読み込まれない**
A: Excellonのフォーマットが `decimal` になっていることを確認してください（KiCadのエクスポート設定）。
